**Дни 4–6 — уровни (F4, один тип — A16)**
L1. **Подсказка:** при первом открытии сверху над графиком — «Удерживайте палец на графике, чтобы поставить уровень» + «Понятно»; после «Понятно» или первого уровня больше не появляется (и после перезагрузки).
L2. **Поставить:** удерживать палец на графике ~0,5 с не двигая — появляется янтарная линия (вибро на Android), цена «прилипает» к ближайшему хаю/лою/открытию/закрытию соседних свечей, если палец в пределах ~12 px, иначе — цена под пальцем с округлением до шага цены. Слева плашка «цена · ТФ». Долгий тап НЕ включает перекрестие графика.
L2a. **Магнит по хвостам (A17):** на Д/Н в отдалённом виде удерживать палец рядом (в пределах ~1 см) с верхним или нижним хвостом свечи — линия ставится ровно на хай/лой хвоста, на хвосте мелькает янтарное кольцо, вибро двойное; в стороне от свечей — линия ставится под пальцем, вибро короткое. Хвост имеет приоритет перед телом свечи.
L3. **Не мешает жестам:** быстрый свайп ленты, горизонтальный пан, пинч, двойной тап — уровень не ставится. Сдвиг пальца > 8 px до 0,5 с отменяет постановку.
L4. **Все ТФ:** уровень, поставленный на 1ч, виден на 5м / Д / Н; на Д и Н полностью отдалённый вид включает все уровни (ни один не за краем).
L5. **Двигать:** взять плашку слева и тянуть вверх/вниз — линия едет, лента и график не двигаются; отпустить — сохранено (перезагрузка страницы → на месте).
L5a. **Магнит при перетаскивании:** вести плашку так, чтобы палец был напротив свечей с хвостом рядом с линией — линия «защёлкивается» на хвост (кольцо, короткое вибро), дальше отпускает, если увести дальше ~24 px.
L6. **Удалить свайпом:** смахнуть плашку вправо > ~60 px — уровень исчезает, внизу «Уровень удалён · Отменить» 5 с; «Отменить» возвращает.
L7. **Тап по плашке:** шторка с ценой и ТФ; заметка до 140 символов (счётчик), «Готово» сохраняет — заметка видна на плашке; «Удалить уровень» → тост «Отменить».
L8. **Список:** кнопка «Уровни N» в нижнем ряду → поиск по тикеру/заметке, группы по тикерам; «Открыть ›» переходит к тикеру в ленте (даже если его нет в текущем источнике); ✕ удаляет.
L9. **Без интернета/логина:** уровни сохраняются локально; после перезагрузки и в другой вкладке того же браузера — на месте.

**Дни 1–3 — лента и график**
1. **Старт:** `/` сразу открывает ленту BTC (вотчлист), без логина и без баннеров «установить приложение». Страница не скроллится, pull-to-refresh не срабатывает.
2. **Свайп ленты:** вертикальный свайп вверх > ~20% высоты или резкий флик — следующий тикер, вниз — предыдущий; короткий медленный свайп — возврат. На первом/последнем тикере — «резинка». Два быстрых свайпа подряд (второй во время анимации первого) — оба срабатывают, ни один не теряется.
3. **Пан графика:** горизонтальный и любой диагональный (> 30° от вертикали, в т.ч. ~45°) жест двигает график, а не ленту. Пинч — масштаб по времени. Вертикальный drag по ценовой шкале справа — масштаб цены (после этого диагональный пан двигает и цену; двойной тап возвращает автомасштаб). Двойной тап — сброс вида.
   - Подержать палец на графике ~0,5 с, затем свайпнуть ленту и вернуться — перекрестие не «залипает». Касание у левого края не вызывает перекрестие.
4. **Левый край:** жест от самого левого края (20 px) не двигает ни ленту, ни график (в iOS Safari работает «назад»).
5. **История:** прокрутить график влево до начала — подгружаются более старые свечи, картинка не прыгает. При долгом пане влево запросы идут не чаще раза в 0,5 с (DevTools → Network, `klines?…endTime`); при ошибке/429 — пауза, без шквала запросов.
   - Быстро пролистать на 5+ тикеров вперёд и сразу вернуться — график первого тикера не пустой.
6. **Живая свеча:** последняя свеча и цена в шапке обновляются в реальном времени.
7. **ТФ:** 4 кнопки 5м / 1ч / Д / Н внизу переключают мгновенно (у пользователя со старыми настройками тоже появилась «Н»); выбранный ТФ сохраняется при свайпе на другой тикер и после перезагрузки.
   - **Д и Н:** график открывается максимально отдалённым — все загруженные свечи по ширине (узкие бары), цена вписана по высоте; двойной тап возвращает этот вид. На 5м/1ч двойной тап — к последним свечам. На Д/Н в полностью отдалённом виде история не догружается сама; приблизить и увести влево — догружается.
8. **Кэш:** перезагрузить страницу — график появляется сразу из кэша, затем догружается хвост (SW-кэш оболочки работает только в prod-сборке, не в `npm run dev`).
9. **Шапка:** тикер, цена с нужной точностью, % за 24ч (зелёный/красный), «Binance · Perp», позиция «3/15».
10. **Источники:** меню справа в шапке → «Топ-50 по объёму», «Движение дня» (только |Δ24ч| > 5%), «Вотчлист», «Избранное». Порядок топ-50 не прыгает во время листания.
11. **Объём:** меню → «Объём: вкл/выкл» скрывает/показывает гистограмму.
11a. **Свечи / бары (A18):** меню шапки → «Вид: Свечи → Бары» — график мгновенно становится OHLC-барами (без «Загрузки»), масштаб и положение не сбрасываются, уровни на месте; перелистнуть на другой тикер и сменить ТФ — тоже бары; после перезагрузки выбор сохранён. Обратно — «Вид: Бары → Свечи». Магнит ставит уровни на хвосты так же.
12. **Ряд действий (внизу, под кнопками ТФ):** правой колонки над графиком больше нет — график на всю ширину. Порядок сверху вниз: шапка → график → 5м/1ч/Д/Н → ряд ★ / Скрыть / Уровни / Список / Скрин; ряд не перекрыт полоской «домой» на iPhone. ★ добавляет/убирает из избранного (сохраняется после перезагрузки); «Скрыть» убирает тикер, «Вернуть» в тосте возвращает; «Уровни N» открывает список уровней (см. L8); «Список» открывает шторку избранного; «Скрин» неактивна. Свайп вверх/вниз по ряду НЕ листает ленту, тапы срабатывают с первого раза.
    - **Скрытые:** меню источника (справа в шапке) → «Скрытые (N)…» — список скрытых тикеров; «Вернуть» возвращает один тикер в ленту, «Вернуть все» — все; после перезагрузки состояние сохраняется.
13. **Избранное:** меню → «Список избранного…»: удаление, «Скачать список» сохраняет `chartswipe-favorites-ГГГГ-ММ-ДД.txt` с `BINANCE:BTCUSDT.P,…` (проверить импорт в TradingView), «Скопировать» кладёт тот же текст в буфер, «Листать избранное» включает источник.
14. **Мелкие монеты:** в «Движение дня»/«Топ-50» у монет с ценой < 0,01 цена в шапке и на шкале показана с достаточной точностью (не 0.00).
15. **Производительность:** переход между тикерами плавный; при 50+ свайпах вкладка не тормозит (DevTools → Performance/Memory по возможности).

**Дни 4–14 — бэкенд, MT5, TradingView** (нужны Supabase-проект, терминал MT5, TradingView)

20. **MT5 тест-скрипт:** скопировать `mt5/ChartSwipeCsv.mqh` и `mt5/tests/ChartSwipeCsvTest.mq5` в `MQL5/Scripts`, скомпилировать, запустить на любом графике → во вкладке «Эксперты» строка `ChartSwipeCsvTest: N passed, 0 failed -> OK`.
21. **MT5 EA на демо:** `ChartSwipeSync.mq5` + `ChartSwipeCsv.mqh` в `MQL5/Experts`, добавить адрес API в «Сервис → Настройки → Советники → Разрешить WebRequest» (для локального теста — `http://127.0.0.1:8000`), указать `ApiKey` и `SymbolSuffix` брокера. Создать уровень через API → в течение ~10 с на графике появляется линия `CS_<id>` нужного цвета (поддержка — зелёная, сопротивление — красная, зона — синий прямоугольник). Изменить цену → линия сдвигается; удалить → линия исчезает. Ручные объекты без префикса `CS_` не трогаются. Перезапуск терминала — уровни на месте, без дублей. Автоторговля не нужна, торговых операций нет.
22. **MT5 на CFT:** то же на счёте пропа; убедиться, что правила пропа разрешают сторонние советники без торговли.
23. **TradingView:** Pine Editor → вставить `pine/chartswipe.pine` → «Добавить на график» компилируется без ошибок. В настройках индикатора вставить строку из `GET /v1/export/pine` (или `BTCUSDT:64200s,65800r,63000-63400z;ETHUSDT:3120s`) → на `BINANCE:BTCUSDT.P` видны 2 линии и синяя зона, на `ETHUSDT.P` — одна линия; панель статуса показывает число уровней и 0 ошибок.
