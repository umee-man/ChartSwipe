# ChartSwipe

Мобильная лента графиков в формате рилсов: свайп вверх — следующий тикер, долгий тап — уровень, и уровень сам появляется в MT5 и TradingView.

> Статус: MVP в разработке. Не торговый терминал и не сигнальный сервис — приложение только готовит разметку.

## Возможности (MVP)
- Вертикальная лента тикеров (вотчлист, топ-50 по объёму, движение дня, ложные пробои сегодня)
- Японские свечи Binance Futures, живое обновление по WebSocket
- Таймфреймы 5м / 1ч / Д одним тапом
- Уровни долгим тапом с магнитом к хаю/лою, зоны, заметки
- Подсветка ложных пробоев дневных уровней
- Синк уровней в MT5 (Expert Advisor) и TradingView (Pine-индикатор)

## Стек
Nuxt 3 PWA · lightweight-charts v5 · Swiper · Pinia · FastAPI · Supabase · MQL5 · Pine Script
