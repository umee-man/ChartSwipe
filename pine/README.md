# ChartSwipe Levels — индикатор TradingView

Индикатор рисует на графике TradingView уровни, которые вы расставили в ChartSwipe. В MVP синхронизация ручная: копируете строку из приложения и вставляете в настройки индикатора (см. architecture.md, A1 и §9).

## Формат строки

```
BTCUSDT:64200s,65800r,63000-63400z;ETHUSDT:3120s
```

| Код | Что рисуется |
|---|---|
| `s` — поддержка | зелёная горизонтальная линия `#2E7D32` |
| `r` — сопротивление | красная горизонтальная линия `#C62828` |
| `z` — зона `низ-верх` | синий полупрозрачный прямоугольник `#1565C0` |

- Символы разделяются `;` (перенос строки тоже подходит), символ и уровни — `:`, уровни между собой — `,`.
- Регистр не важен. Префикс биржи (`BINANCE:BTCUSDT:...`) и суффикс `.P` допускаются.
- Ошибочные записи пропускаются, график при этом не ломается. Их количество показывает панель статуса в правом верхнем углу.
- **Цены — только обычные десятичные числа** с точкой: `64200`, `0.00003`, `63000.5`. Без экспоненты (`3e-05`), без разделителей тысяч (`64 200`, `64,200`) и без знака. Генераторы (`api` — `GET /v1/export/pine`, `web/lib/pine`) обязаны форматировать цену без экспоненты: в Python `format(Decimal(x), 'f')`, в TS — форматтер без экспоненты (не `String(x)`, который для `0.0000001` даёт `1e-7`).

## Тестовые векторы

`pine/test_vectors.json` — общие примеры «строка → уровни» для контракта §7/§9. Парсер индикатора повторён на Python в `pine/tests/pine_sim.py`:

```
python pine/tests/pine_sim.py
```

Генераторы `api` и `web/lib/pine` должны прогонять свой вывод через эти же векторы (сгенерировать строку → разобрать симулятором → сравнить уровни).

Симулятор не заменяет TradingView. **QA, вручную:** после каждого изменения `chartswipe.pine` вставить файл в Pine Editor, убедиться, что он компилируется без ошибок, и проверить на графике `BINANCE:BTCUSDT.P` строку из примера выше.

## Как добавить индикатор

1. Откройте TradingView, затем график перпа Binance, например `BINANCE:BTCUSDT.P`.
2. Внизу экрана откройте **Редактор Pine** (Pine Editor).
3. Создайте новый индикатор: **Открыть → Новый индикатор**. Удалите шаблонный код.
4. Вставьте содержимое файла `pine/chartswipe.pine` целиком.
5. Нажмите **Сохранить**, назовите скрипт `ChartSwipe Levels`.
6. Нажмите **Добавить на график**.

Индикатор сохранится в разделе **Индикаторы → Мои скрипты**, и его можно добавить на любой график.

## Как вставить строку из приложения

1. В ChartSwipe откройте **Интеграции → TradingView** и скопируйте строку. Её же отдаёт `GET /v1/export/pine`.
2. На графике TradingView наведите курсор на название индикатора `ChartSwipe` и нажмите на шестерёнку (**Настройки**).
3. На вкладке **Аргументы** вставьте строку в поле **«Строка уровней из ChartSwipe»**.
4. Нажмите **ОК**.

Индикатор выбирает из строки только уровни текущего символа: на `BTCUSDT.P` рисуются уровни `BTCUSDT`. Одну и ту же строку со всеми символами можно вставить в индикатор на каждом графике.

## Как обновить уровни

Если вы добавили, сдвинули или удалили уровни в приложении:

1. Скопируйте в ChartSwipe новую строку.
2. Откройте настройки индикатора, **замените** в поле старую строку на новую и нажмите **ОК**.

Индикатор каждый раз стирает всё, что нарисовал, и строит уровни заново, поэтому дубликатов не будет.

Чтобы одна строка работала на всех графиках, сохраните её как шаблон: внизу окна настроек нажмите **Шаблоны → Сохранить как**. Новую версию строки можно сохранить в тот же шаблон.

## Настройки на вкладке «Вид»

- Цвета поддержки, сопротивления и зоны, прозрачность заливки зоны.
- **«Начало зоны: баров назад»** — с какого бара начинается прямоугольник зоны. Вправо зона продлевается бесконечно.
- Толщина линий, подписи с ценой, панель статуса.

## Ограничения

- До 500 линий и 500 зон на одном графике (лимит Pine). Если лимит превышен, панель статуса покажет предупреждение.
- Подписи с ценой: общий лимит 500 на линии и зоны вместе. Если уровней больше 500, у части не будет подписи, а панель статуса покажет «подписи: лимит 500». Сами линии и зоны при этом рисуются.
- Автоматической синхронизации с TradingView в MVP нет: у TradingView нет публичного API. Она появится в v1.
- Символы сравниваются по `syminfo.ticker`. Для тикеров не с Binance (например, `BTCUSD` у другой биржи) нужно, чтобы в строке стоял тот же тикер.
